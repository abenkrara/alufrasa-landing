# ALUFRASA — Carpintería de Aluminio y PVC en Valencia

Landing page de alta conversión (CRO) y diseño premium para **ALUFRASA**, taller especializado en carpintería de aluminio, ventanas de PVC con aislamiento térmico/acústico y cerramientos en Valencia.

## 🚀 Características
- **Optimizado para CRO**: Botones directos a llamada telefónica y WhatsApp contextual con mensaje prefijado.
- **Rendimiento Ultrarrápido**: HTML5 semántico puro + Tailwind CSS vía CDN, sin dependencias pesadas.
- **SEO Local & Schema.org**: Marcado estructurado JSON-LD tipo `HomeAndConstructionBusiness` con geolocalización de Valencia, Benicalap y áreas metropolitanas.
- **100% Responsive & Mobile-First**: Diseñado específicamente para usuarios móviles que buscan presupuestos rápidos.

## 📦 Despliegue en Vercel
Este proyecto es estático y no requiere pasos de compilación:
1. Conecta este repositorio en [Vercel](https://vercel.com/new).
2. Selecciona el framework **Other**.
3. Haz clic en **Deploy**.
